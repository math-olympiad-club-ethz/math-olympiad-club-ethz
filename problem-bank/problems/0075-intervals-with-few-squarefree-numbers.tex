\begin{problem}
\noindent A number is squarefree, if it doesn't have a repeated prime factor. Prove that for every integer $n$ there is an integer $a$ such that $\{a+1,\ a+2\dots a+n\}$ contains exactly $\lfloor\frac{n}{4}\rfloor$ squarefree numbers.
\end{problem}
