\begin{problem}
Let \(n \ge k \ge 3\) be integers. Show that for every integer sequence
\[
1 \le a_1 < a_2 < \cdots < a_k \le n
\]
one can choose non-negative integers \(b_1,b_2,\dots,b_k\) satisfying:

\begin{enumerate}
    \item \( 0 \le b_i \le n\) for each \(1 \le i \le k\),
    \item all the positive \(b_i\) are distinct,
    \item the sums \(a_i + b_i\), \(1 \le i \le k\), form a permutation of the first \(k\) terms of a non-constant arithmetic progression.
\end{enumerate}
\end{problem}
