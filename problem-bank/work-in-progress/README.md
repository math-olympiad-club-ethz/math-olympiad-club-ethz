# work-in-progress/ — problems still in construction

This folder is **git-ignored**: its content stays on your own computer and is never committed or published.
Only this README is tracked, so that everyone knows the folder exists.

Put a problem here while it is unfinished (statement or solution still being written). When it is ready,
move it to `problem-bank/problems/` as `new-title.tex` with its header (see `problem-bank/README.md`); it gets its
number automatically when it is merged.

Not backed up by GitHub: keep your own backup of anything important in here.
